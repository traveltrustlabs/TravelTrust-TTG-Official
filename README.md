## What is TravelTrust

TravelTrust is an Ethereum travel-commerce protocol: marketplace matching, on-chain Escrow for traveler principal in Circle USDC, and TTG governance.

## What is TTG

**TTG** (TravelTrust Governance) is the governance token:

- Ethereum Mainnet
- Fixed supply **25,000,000,000,000** (25T)
- **18** decimals
- **No additional mint** after genesis
- **Not** trip collateral — travel deposits use Circle USDC

**Mainnet TTG contract:**  
`0xd9965802ff0A9DAB5d0E13392dA797cd6D13ee51`  
[View on Etherscan](https://etherscan.io/token/0xd9965802ff0A9DAB5d0E13392dA797cd6D13ee51)

Verified contract source is published on Etherscan. This repository is **documentation and public references** (not a full Solidity monorepo).
